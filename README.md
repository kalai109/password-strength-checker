
# Password Strength Checker

## About the Project
The Password Strength Checker is a beginner-friendly Python cybersecurity project that evaluates password strength based on common security criteria.

## Features
- Checks password length.
- Checks for uppercase letters.
- Checks for lowercase letters.
- Checks for numbers.
- Checks for special characters.
- Classifies passwords as Weak, Medium, or Strong.
- Provides suggestions to improve password security.

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python password.py
   ```

6. Enter a sample password when prompted.

## Sample Output

```text
=== Password Strength Checker ===
Enter a password to check: hello

Password Strength: Weak

Suggestions to improve your password:
- Use at least 8 characters.
- Add an uppercase letter (A-Z).
- Add a number (0-9).
- Add a special character, such as ! or @.
```

This project is for educational purposes only. The strength classification is a basic demonstration and does not guarantee that a password is secure.
